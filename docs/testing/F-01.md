## NFR02: Testbestand und Messung (OF-F01-4)

- **Testbestand:** 1 000 aktive Titel mit je 2 Exemplaren, jedes dritte Exemplar ausgeliehen, 12 Kategorien, Erscheinungsjahre 1950 bis 2024. Angelegt per SQL im Test.
- **Messung:** Zeit eines Aufrufs von `sucheKatalog` auf dem Server (ohne Netzwerk und Seitenaufbau), nach einem Aufwärm-Aufruf. Geprüft werden fünf typische Anfragen (ohne Begriff, Begriff, Begriff mit Filter und Sortierung, Filter mit Seite 2, Inventarnummer). Jede muss unter 1 000 ms liegen.
- Die Messung läuft in PGlite. Ein echter PostgreSQL-Server ist in der Regel schneller; die Zeiten stehen im Testlauf von GitHub Actions, nicht in diesem Dokument.

## Annahmen der Tests (aus der Spec abgeleitet, zum Nachfragen markiert)

| Punkt | Annahme | Grundlage |
|---|---|---|
| Jahresfilter | Grenzen `jahrVon`/`jahrBis` sind eingeschlossen; eine Grenze allein ist erlaubt | AK-02.3 „Jahresbereich“ |
| Gleichstand beim Sortieren | Titel immer **aufsteigend**, auch wenn das Hauptmerkmal absteigend sortiert ist | AK-02.5 „bei Gleichstand nach Titel“, OF-F01-3 |
| Teilwortsuche | gilt auch für ISBN und Inventarnummer (z. B. `INV-9010` findet `INV-901001`) | AK-01.5 |
| Kategorie-Filter | exakter Vergleich mit dem gespeicherten Text | AK-02.1, OF-D5 |
| Seite | `seite < 1` ergibt `VALIDIERUNG` mit Feld `seite` | schnittstellen.md „Ganzzahl ≥ 1“ |
| Sonderzeichen | `%` und `_` sind normale Zeichen (kein Platzhalter) | AK-01.9 |
| Ziel nach der Anmeldung (R-01) | Ein Ziel, das der Browser auf eine fremde Herkunft auflösen würde (`//host`, `/\host`, Tabulator, `/.//host`, absolute URL), wird zu `/`. Ein kodierter Backslash (`/%5Chost`) ist ein Pfad der eigenen Herkunft und muss nicht zu `/` werden. Der Test ersetzt Datenbank, Sitzung und `redirect`, damit nur die Wahl des Ziels geprüft wird. | Rechte-Matrix „Gast“ (Weiterleitung zur Anmeldung), E06-US01-FR02; Befund R-01 |
