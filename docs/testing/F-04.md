## Annahmen der Tests

| Punkt | Annahme | Grundlage |
|---|---|---|
| Fortlaufend | jede neue Nummer ist die vorige + 1, über alle Titel hinweg; mit welcher Zahl die Zählung beginnt, ist offen | OF-D6 „fortlaufend vom System vergeben“ |
| Zahlenbereich | 1 bis 999 999; außerhalb wirft `formatiereInventarnummer` einen Fehler | OF-D6 „sechsstellige Zahl“ |
| Zustand beim Anlegen | alle drei Zustände sind beim Anlegen erlaubt, unbekannte ergeben `VALIDIERUNG` mit Feld `condition` | AK-02.1, AK-02.3 |
| Zustandswerte | nur genau `GUT`, `BESCHAEDIGT`, `VERLOREN` (Großbuchstaben, ADR 001) | OF-D3 |
